How to read this page
  • This page is built from real Play Store reviews of the MoveInSync employee app. It updates every time the tool runs.
  • Written review = a star rating that comes with text. Bad review = 1 or 2 stars.
  • "Last 90d" = the last 3 months. "vs prior period" = compared with the 3 months before that.
  • Stars lost = how far a review is from 5★. A 1★ review loses 4 stars, a 4★ review loses 1. Adding these up per problem shows which problems hurt the rating most.
  • pts = percentage points. Going from 24% to 35% is +11 pts.
